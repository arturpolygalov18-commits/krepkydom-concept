# Крепкий Дом: демонстрационный концепт

Вариант оформления первых блоков сайта, подготовленный Артуром Полыгаловым для обсуждения с компанией «Крепкий Дом», Томск. Это демонстрация дизайна, не официальный сайт компании и не завершённый клиентский проект.

Исходный сайт: https://ooodom70.ru/

Логотип, фотографии и визуализации проектов взяты с сайта компании. Права на исходные материалы принадлежат их правообладателям. Фон изображения дома в технологическом блоке удалён для композиции. Ссылки на каталог и страницы проектов ведут на действующий сайт компании.

Основная проработка выполнена для компьютера.
